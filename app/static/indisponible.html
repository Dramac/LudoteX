Le site de prêt ne répond pas pour le moment

Votre téléphone et le réseau fonctionnent : c'est l'application qui est arrêtée ou qui redémarre. Prévenez le bureau.

Si vous étiez en train de prêter ou de rendre un jeu, ce geste n'a peut-être pas été enregistré. Ne réessayez pas en boucle : continuez sur papier.

Pendant la coupure, sur une feuille

  • Prêt : glissez la pièce d'identité dans la pochette vide qui porte le plus petit numéro. Notez le code de la boîte (le grand nombre sous le QR), le numéro de pochette et « prêt ».
  • Retour : rendez la pièce d'identité. Notez le code de la boîte, le numéro de pochette et « retour ».

Quand le site revient

Avant tout nouveau prêt, reprenez la feuille dans l'ordre : pour chaque ligne, ouvrez la boîte (scan ou code tapé) et refaites le geste. Le numéro de pochette affiché par l'application fait foi : s'il diffère de celui de la feuille, déplacez la pièce d'identité dans la pochette affichée.

Revenir au scanner — la page s'ouvrira dès que l'application répondra de nouveau.
